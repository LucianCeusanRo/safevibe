SafeVibe
local only · 127.0.0.1

Nothing in this UI is sent to a cloud model. Redaction and scanning run on this machine.

Limits — read this first

Pseudonymization is not encryption. If you point the proxy at a cloud model, a transformed prompt still leaves the machine. SafeVibe is not for classified data or “secrete de serviciu”, is not a certification, and a green scan is not a guarantee of safety.

Redaction preview

Paste a prompt. SafeVibe replaces secrets, addresses, Romanian CNP/CUI and dictionary terms with placeholders. The originals stay in a local vault and are not shown here.

Static scanner

Point at a local folder, a skill, an MCP server, a VS Code extension or a package. SafeVibe only reads files. It never installs or runs the target.
